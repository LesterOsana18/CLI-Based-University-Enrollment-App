# 🎓 Automated University Enrollment App

## 📘 Overview
**Automated University Enrollment App** is a basic CRUD-based **Educational Portal** built with Java.

It helps manage university enrollment workflows such as course setup and student scheduling.

## 🧾 Description
This project is designed to:
- 👤 Manage student and employee user records
- 📚 Support course creation and maintenance
- 🗓️ Handle student course enrollment per term
- ✅ Enforce prerequisite validation before enrollment
- 🏫 Keep enrollment data organized by school year and semester

## 🚀 Core Features
- **Student Management** (Create, Read, Update, Delete)
- **Course Management** (Create, Read, Update, Delete)
- **Enrollment Management** (Create, Read, Update, Delete)
- **Department-based organization**
- **Role-based users** (Student, Registrar, Admin)
- **Strict prerequisite checking** for enrollment validation

## 🛠️ Tech Stack
- **Language:** Java ☕
- **Database:** MySQL 🐬
- **Architecture:** Basic CRUD Application

## 🎯 Goal
The goal of this project is to provide a simple but structured enrollment system for educational use, with emphasis on data consistency and prerequisite compliance.
